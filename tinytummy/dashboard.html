⚙️ Connect Supabase first

This dashboard needs your Supabase project. Three steps:

  1. In Supabase: SQL editor → run supabase/schema.sql from this repo.
  2. Project Settings → API → copy the URL and anon key into js/supabase-config.js.
  3. Authentication → Users → “Add user” to create your own admin login (email + password).

Reload this page when done.
